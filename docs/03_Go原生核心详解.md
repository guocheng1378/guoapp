# 真果鉴 Code Wiki — Go 原生核心详解

## 1. 模块组织一览

Go 原生核心位于 `native/core/`，共 **101 个非测试文件 + 27 个测试文件**。按职责分为以下子模块：

| 模块 | 文件数 | 核心文件前缀 | 职责 |
| --- | --- | --- | --- |
| **运行时与入口** | 4 | `app_runtime`, `config_defaults`, `diagnostics`, `helpers` | Downloader 单例、配置结构、请求路由分发 |
| **站源 Provider** | ~45 | `provider_*` | 各短剧站源的目录/详情/搜索/播放解析 |
| **网络层** | 9 | `network_*`, `proxy_system` | HTTP 客户端、DNS、CDN、限流、代理、浏览器指纹 |
| **数据模型** | 3 | `models`, `library`, `media_playlist` | Drama/Chapter/Task 结构体、库管理、播放列表解析 |
| **应用层功能** | ~30 | `app_*` | 缓存、封面、弹幕、下载、播放、存储、分类、推荐、榜单、局域网 |
| **UI 辅助** | 3 | `ui_*` | 给 UI 层的特殊接口（剧集刷新、弹幕流式、任务） |

## 2. Downloader：核心调度单例

```go
// app_runtime.go
type Downloader struct {
    cfg                   Config
    client                *http.Client     // 带 TLS 指纹的 HTTP 客户端
    limiter               *requestLimiter  // 请求限流器
    proxyRouter           *proxyRouter     // 代理路由
    rankings              rankingCache     // 榜单缓存

    // 各站源独立客户端（sync.Once 延迟初始化）
    hongguo               *hongguoAppClient
    huangju               *huangjuAPIClient
    yeguo                 *yeguoAPIClient
    dsdCatalog            dsdCatalogState
    legacy                *legacyAPIClient  // 黄豆/黄果旧版

    // 短剧 Provider 由 dispatch 动态分发（无独立 client 字段）
    duanjuPreviewSessions map[string]*huangguoPreviewSession

    diagnostics           *diagnosticLog    // 诊断日志
}
```

Downloader 在 `core.NativeRequest()` 调用路径中通过全局单例访问：

```go
// bridge/main.go → core.NativeRequest(body string)
// NativeRequest 内部调用 defaultDownloader().handle(input)
```

### 3.2 Provider 分发架构

传统 Provider（红果、黄豆、剧果、野果、帝果、黄果）各自独立实现接口。

12 个"x 果"短剧站源由 **`provider_duanju_dispatch.go`** 统一分发：

```go
func (d *Downloader) fetchDuanjuCatalogPage(ctx context.Context, source string, page int, category string) ([]Drama, bool, error) {
    switch source {
    case sourceYaguo:   return d.fetchYaguoCatalogPage(ctx, page, category)
    case sourceMaoguo:  return d.fetchMaoguoCatalogPage(ctx, page, category)
    // ... 各独立实现
    case sourceHuaguo, sourceFaguo, sourceWuguo, sourceWangguo, sourcePiguo:
        return d.fetchMaccmsCatalogPage(ctx, source, page, category) // 共用 maccms 解析
    }
}
```

```go
// provider_duanju.go
var duanjuSourceAliases = map[string]string{
```

### 5.2 各站源取流特点

| 站源 | 取流机制 | 文件 |

## 6. 下载子系统

### 6.1 架构

```
Flutter 调用 enqueueDownloads()
         ↓
  app_downloads.go — enqueueNativeDownloads()
         ↓
  app_download_transfer.go — 分片下载（多 goroutine + 续传）
         ↓
  app_download_hls.go — HLS 分片合并（AES-128 解密 + ffmpeg 转封装）
         ↓
  文件写入设备存储
```

### 6.2 下载调度

- **默认并发 2**，可在 1-6 调整
- **Range 续传**：站源支持时断点续传；不支持时重下
- **失败重试**：完整 HLS 分片可复用
- **批次上限**：每次 500 个任务、单次 50 部批量下载
- **后台运行**：Android 前台服务 + 通知栏进度

### 6.3 下载格式

| 源格式 | 保存内容 |
| --- | --- |
| MP4 | 原始 MP4 文件 + 必要密钥文件 |
| HLS | 选中画质 m3u8 列表、所有分片、AES-128 密钥、默认音轨/字幕 |
| CENC MP4 | 视频文件 + 密钥（不自动解密） |

## 7. 数据模型（Go 端）

### 7.1 Drama（`models.go`）

```go
type Drama struct {
    ID                string             `json:"id"`
    Source            string             `json:"source,omitempty"`
    SourceID          string             `json:"sourceId,omitempty"`
    Title             string             `json:"title"`
    Name              string             `json:"name"`     // 部分站源用 name
    Cover             any                `json:"cover"`    // 多形态，需 coverPathFromAny 解析
    CoverURL          any                `json:"coverUrl"` // 兼容多字段
    TotalEpisode      any                `json:"totalEpisode"` // 多种命名变体
    TotalEpisodeSnake any                `json:"total_episode"`
    Category          string             `json:"category"`
    VIP               *bool              `json:"vip,omitempty"`
    Score             string             `json:"score,omitempty"`
    Views             string             `json:"views,omitempty"`
    Heat              string             `json:"heat,omitempty"`
    OnlineDate        string             `json:"onlineDate,omitempty"`
    Tags              []string           `json:"tags,omitempty"`
    ReleaseStatus     string             `json:"releaseStatus,omitempty"`
}
```

> 注意：`Cover`、`TotalEpisode` 等字段用 `any` 类型是因为不同站源返回 JSON 字段名差异极大（cover / coverUrl / cover_url / image / img / pic / poster / thumbnail...），统一由 `coverPathFromAny()` 函数递归解析。

## 8. 本地缓存与持久化

### 8.1 目录缓存（`app_catalog_cache.go`）

```
策略：
├─ 目录条目 + 页码缓存 15 分钟
├─ 过期后先显示缓存、后台更新
├─ 红果总目录/分类 各自保存 offset + 会话 + 分页签名
├─ 续页按保存位置续请求
├─ 32 MiB 保存上限
└─ 失败保留内存，不截断
```

### 8.2 封面缓存（`app_covers.go`, `app_cover_metadata.go`）

```
策略：
├─ 有效期 30 天
├─ 上限 256 MB / 2000 张
├─ 单张上限 20 MB
├─ HEIC 主图 → 随包媒体库转 JPEG
├─ AES / XOR 解码支持
├─ 过期更新失败继续显示缓存
└─ 重复请求合并 + 重试间隔
```

### 8.3 排行榜缓存（`provider_rankings_loader.go`）

```
策略：
├─ 红果榜单解析结构化数据 + JSON-LD + 语义化条目
├─ 最多重试 3 次，总时限 18s
├─ 成功结果缓存 5 分钟
├─ 24 小时回退旧榜单
└─ 失败刷新保留已有列表
```

## 9. 弹幕系统（`app_danmaku.go`, `danmaku_emoji.go`）

红果弹幕在 Go 核心完成表情转换：
- 弹幕文本内嵌 `[笑哭]` 一类表情代码
- `danmakuEmojiMap` 内置对照表 → 转换为 Unicode emoji
- 未收录代码原样保留
- 截断逻辑：在变体选择符 (U+FE0F) / 零宽连接符 (U+200D) 之前回退，避免组合表情被截

Flutter 端（`danmaku_controller.dart` + `danmaku_overlay.dart`）负责：
- 文字测量 + 线性动画移动
- 暂停/缓冲时停止
- 倍速/跳转按视频时间同步

## 10. 局域网互联（`app_lan.go`, `app_lan_http.go`）

### 10.1 发现协议

```
服务类型：_zgj-link._tcp (DNS-SD / mDNS)
发布信息：设备名 + 设备ID + 端口 + 协议版本 + 证书指纹 + 同步/播放能力
设备ID：稳定 UUID，多网卡地址合并
证书：首次配对后固定校验指纹
```

### 10.2 同步协议

```
范围：追剧列表 + 想看/在看/已看状态 + 新集已读基准 + 续播进度
粒度：每设备每用户独立副本 ID + 递增计数
合并规则：版本向量判断先后，不依赖设备时钟
冲突：无法判断时保留候选 → 用户手动选择
传输：仅发送差异条目 + 删除标记，不传完整备份
```

### 10.3 手动同步选项

| 模式 | 行为 |
| --- | --- |
| 双向合并 | 合并双方 → 两端同写 |
| 覆盖对方 | 本机替换对方 |
| 覆盖本机 | 对方替换本机 |
