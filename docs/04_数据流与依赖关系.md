# 真果鉴 Code Wiki — 数据流与依赖关系

## 1. 启动数据流

```
Flutter main()
  │
  ├─ WidgetsFlutterBinding.ensureInitialized()
  ├─ MediaKit.ensureInitialized()
  ├─ windowManager.ensureInitialized() [Windows]
  └─ runApp(AppBootstrap)
       │
       ├─ SharedPreferences.getInstance()       ← 加载本地偏好
       ├─ AppDevice.detect()                      ← 判断 phone/TV/computer
       │
       ├─ NativeRepository.initialize()
       │    └─ FFI → Go Downloader.initialize()
       │         ├─ 读取 dataDir
       │         ├─ 加载站源配置
       │         ├─ 初始化 HTTP client（tls-client）
       │         ├─ 建立目录缓存 SQLite
       │         └─ 启动下载调度 goroutine
       │
       ├─ LocalStore(preferences)                 ← 构建快照、恢复用户
       ├─ MediaLibrary.attach(repository, store)  ← 加载下载索引
       ├─ LanController(...)                      ← 局域网服务初始化
       │
       └─ DuanjuApp
            └─ HomeScreen (或 ProfilesScreen 锁定时)
```

## 2. 目录浏览数据流

```
用户点击首页
  │
  ▼
HomeScreen._loadPage()
  │
  ├─ repository.categories(source) ──────→ Go: fetchCategories()
  │                                         ├─ 红果: hongguoAppClient.categories()
  │                                         ├─ 剧果: huangjuAPIClient.getCategories()
  │                                         ├─ 短剧 Provider: fetchDuanjuCategories()
  │                                         └─ 缓存命中时直接返回
  │
  ├─ repository.catalog(source, page=1, category) ──→ Go: fetchCatalog()
  │                                                      ├─ 先查 catalog cache (15min TTL)
  │                                                      ├─ 缓存未命中 → Provider.fetchXxxCatalogPage()
  │                                                      ├─ 响应去重、规范化 Drama 结构
  │                                                      └─ 写回 cache
  │
  └─ 渲染卡片列表（封面、标题、分类、更新标记）
       │
       ├─ repository.cover(drama) → Go: cover(drama)
       │    ├─ 本地缓存命中 → 直接返回文件字节
       │    └─ 缓存未命中 → HTTP GET → 写入缓存 → 返回字节
       │
       └─ CoverDecoder.decode(coverBytes) → 图像显示
            ├─ PNG/JPEG: 直接传递
            └─ HEIC: 调随包媒体库转 JPEG
```

## 3. 播放数据流

```
用户点击剧集卡片
  │
  ▼
PlaybackLoader.load(drama, episode, quality)
  │
  ├─ repository.resolve(drama, episode, quality)
  │    │
  │    ▼ FFI → Go: resolvePlayback()
  │         ├─ dramaProvider() → 识别来源站源
  │         ├─ Provider.fetchDetail() → 获取分集列表
  │         ├─ Provider.resolveMedia() → 提取媒体地址
  │         │    ├─ 红果: hongguoAppClient.mediaDetail() → 签名
  │         │    ├─ 剧果: huangjuAPIClient.play() → CloudFront Cookie
  │         │    ├─ 野果: yeguoAPIClient.parseMedia() → AES-CBC
  │         │    ├─ 帝果: dsdCatalogState.resolvePlayback() → aaencode
  │         │    └─ 短剧 Provider: resolveDuanjuMedia()
  │         │
  │         ├─ 解析播放列表（m3u8 / mp4）
  │         │    ├─ media_playlist.Parse() → MediaSegments + AES key
  │         │    └─ 生成 PlaybackPlan（含所有 headers/cookies）
  │         │
  │         └─ 启动本地 playback_gateway (localhost:xxxxx)
  │              └─ 注册 session → 接收 media_kit 的 Range 请求
  │
  ▼
  Flutter 得到 PlaybackPlan
  │
  ├─ 创建 media_kit.Player
  │    ├─ player.open(Media(plan.url, httpHeaders: plan.headers))
  │    └─ 自动建立解码器、视频输出
  │
  ├─ DanmakuController.start(plan)  [仅红果在线]
  │    └─ repository.danmaku(plan, startMs, durationMs)
  │         └─ Go: fetchDanmaku() → 拉弹幕 → 表情转换
  │
  ├─ PlaybackPreloader.scheduleNext(currentPlan)  [自动连播]
  │    ├─ 时机：播放 ≥2s + 缓冲余量 ≥5s + 进入后半段或最后45s
  │    ├─ 解析下一集地址（15s 时限）
  │    └─ 预取开头（最多 6s / 4 MiB / 8 次请求）
  │
  └─ 用户控制（手势 / 按钮 / 键盘）
       ├─ 暂停、倍速、跳转
       ├─ 上一集 / 下一集
       ├─ 画质切换 → 重新 resolve 同剧不同 quality
       └─ 播放失败 → PlaybackRecovery
            ├─ 切备用地址（fallback）
            ├─ 降画质
            └─ 重新解析（最多 1 次）
```

## 4. 下载数据流

```
用户在详情页/批量下载选择分集
  │
  ▼
enqueueDownloads(detail, episodes, quality)
  │
  ▼ FFI → Go: enqueueNativeDownloads()
       ├─ 生成 Task 列表
       │    ├─ 解析 OutPath（按站源分类 / 剧分组）
       │    └─ 读取已下载文件 → 跳过重复
       │
       ├─ app_download_transfer.go
       │    ├─ 任务入队（优先级：前台下载 > 后台）
       │    ├─ 并发调度（默认 2 并发）
       │    ├─ Range 检测 → 续传或重下
       │    └─ 进度回调（通知 Flutter 更新 UI）
       │
       └─ HLS 处理（如果源是 m3u8）
            ├─ 下载所有分片
            ├─ app_download_hls.go
            │    ├─ AES-128 解密（如果有）
            │    ├─ ffmpeg 转封装（分片 → 单个 MP4）
            │    └─ 更新合并队列
            │
            └─ 合并完成 → 更新下载索引版本
```

## 5. 局域网同步数据流

```
Flutter LanController (lan_controller.dart)
  │
  ├─ 发现阶段
  │    └─ nsd 包发布/发现 _zgj-link._tcp 服务
  │    └─ 设备面板显示候选（手机/电脑/电视图标 + 证书状态）
  │
  ├─ 连接阶段
  │    └─ TLS 双向握手 + 证书指纹校验
  │    └─ 协议能力协商（双方站源集合交集）
  │
  ├─ 自动同步（双向合并）
  │    ├─ 首次：交换版本摘要 → 合并差异
  │    ├─ 追剧增删 → 短暂合并后发送
  │    ├─ 播放中：每 ~10s 发送最新进度
  │    ├─ 暂停/切集/退出 → 立即补发
  │    └─ 断线：本地记录，重连后补齐
  │
  └─ 推送播放
       ├─ 发起端：preload() → prepareHandoff() → 发送 handoff 事件
       └─ 接收端：openPlayback callback → 验证 → 打开 PlayerScreen
```

## 9. 数据序列化约定

Flutter ↔ Go JSON 交互的关键约定：

1. **错误返回**：`{"ok": false, "error": "具体原因", "code": "可选错误码"}`
2. **空值处理**：Go 端对缺失字段填充空字符串/零值，避免 `null` 导致 Dart 解析失败
3. **封面 URL**：Go 端 `coverPathFromAny()` 统一处理 15+ 种字段名变体，Flutter 直接使用字符串
4. **剧集 ID**：格式为 `"站源标识:源站内部ID"`（如 `hongguo:abc123`），`splitProviderDramaID()` 统一解析
5. **VIP 标记**：`null` 表示未知、`true` 表示 VIP、`false` 表示免费

## 10. 并发模型

### Flutter 端

- `NativeRepository._call()` 所有 FFI 调用在主线程外的 Isolate 执行
- `PlaybackPreloader`、`DanmakuController`、`LanController` 各有独立异步流程
- `LocalStore` 所有写入通过串行队列 + 完整快照提交

### Go 端
