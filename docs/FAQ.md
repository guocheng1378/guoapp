# 常见问题（FAQ）

面向使用者的常见问题。开发与贡献相关请看 [CONTRIBUTING.md](../CONTRIBUTING.md)。

## 播放相关

**Q：点开剧一直转圈或提示失败？**

依次尝试：① 在「站源管理」里对当前源执行连接与播放检测；② 播放页打开线路菜单切换线路；③ 下拉刷新或稍后重试（部分站源偶发抖动）；④ 剧卡菜单「换个源找」，从其他站源搜同名剧。

**Q：为什么有的剧只有部分源能搜到？**

各站源收录内容不同，且默认只开启部分站源；受限站源需要在「站源管理」中开启（见下）。

**Q：弹幕怎么没有？**

弹幕目前仅在部分站源提供（红果、真果·鉴）。播放页工具栏的弹幕徽标会显示当前状态（不支持 / 加载中 / 暂无 / N 条）。

**Q：VIP 内容怎么处理？**

点播 VIP 内容会先弹出确认提示。不想看到 VIP 剧，可在首页顶栏开启「VIP 隐藏」。

## 站源与权限

**Q：受限站源（黄果类、成人类）怎么开启？**

先在「设置 → 用户管理」设置管理员密码，再到「站源管理」逐个或一键开启；开启受限源需要输入密码。黄果类 / 成人类分组默认整组隐藏，解锁后才在分组中出现。

**Q：激活码怎么用？**

进入「用户管理」或「关于」页的激活入口，输入卖家提供的激活码（一码一机，激活后记录保存在本机）。激活状态可在设置中查看。购买或续期请联系 QQ：963484350。

## 下载与数据

**Q：怎么批量下载？**

剧卡右上角菜单 →「多选下载」，勾选剧集后批量加入下载队列，下载页可查看进度。

**Q：我的数据会上传服务器吗？**

不会。应用没有自建服务端，观看记录、收藏、下载都在本机。跨设备可用局域网互联（同一 Wi-Fi 下同步追剧与推送播放），或使用 WebDAV 云备份。

## 更新

**Q：怎么更新？**

应用启动时会自动检查新版本并弹窗，点「立即更新」下载整包安装即可；没有弹窗说明已是最新版本。

**Q：Windows 版怎么运行？**

下载 zip 解压后运行目录内主程序即可，无需安装。

## 直播

**Q：直播频道打不开或有广告？**

应用会自动剔除广告 / 购物类伪频道；某频道线路不佳时可在直播页切换线路。直播源来自公共聚合，可用性随上游波动。

## 反馈

**Q：怎么报 bug？**

「设置 → 反馈 Bug」会自动附上版本与环境信息，可一键到 GitHub Issues，也可复制内容另发。紧急联系 QQ：963484350。
