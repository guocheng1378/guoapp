# 真果鉴 Code Wiki — 项目架构概览

## 1. 项目定位

**真果鉴 / 红果鉴**（原名"短剧库 APP"）是一款 Flutter 多端独立短剧应用。核心设计原则是：**所有站源请求、解析、在线播放及下载、合并均在设备端完成**，不依赖旧短剧库程序、旧项目路径或远程自建服务。

| 项 | 值 |
| --- | --- |
| 当前版本 | 0.2.55+61（开发快照） |
| 构建系统 | Flutter + FFI 混合架构 |
| 源码规模 | Flutter 81 个 Dart 文件（约 500 KB）；Go 101 个核心文件（约 26,000 行） |
| 测试覆盖 | Flutter 29 单元测试 + 3 集成测试；Go 27 测试文件 |

## 2. 双版本编译

项目通过构建脚本 `scripts/app_build.py` 支持两种编译模式：

| 编译参数 | 应用名称 | 可用站源 |
| --- | --- | --- |
| 默认 | 红果鉴 | 仅红果（hongguo） |
| `--all-sources` | 真果鉴 | 红果 + 黄豆 + 剧果 + 野果 + 帝果 + 黄果 + 12 个短剧站源 |

> 两版共用同一应用标识和数据目录，Android 可相互覆盖升级。

## 5. 关键分层职责

### Flutter 前端 (`lib/`)

- **UI 渲染**：首页、详情页、播放器、下载管理、追剧、设置等 20+ 页面
- **状态管理**：`LocalStore` 负责用户隔离的本地状态快照（追剧、历史、偏好）
- **平台适配**：Android / Windows / iOS 平台分支，Android TV 遥控器焦点
- **媒体播放**：`media_kit` 视频播放控制器，弹幕覆盖层，手势交互
- **网络桥接**：通过 FFI 序列化 JSON 与 Go 核心交互

### Go 原生核心 (`native/core/`)

- **站源接入**：对 20+ 短剧站源分别实现目录、详情、搜索、播放解析
- **网络层**：自定义 HTTP 客户端、TLS 指纹伪装、请求限流器、代理路由
- **播放解析**：HLS / MP4 地址提取、签名 Cookie 管理、vPlayer aaencode 解码
- **下载调度**：队列管理、并发控制、HLS 分片下载与 AES-128 密钥处理
- **数据持久化**：SQLite 目录缓存、进度保存、配置读写
- **局域网互联**：DNS-SD 发现、追剧双向同步、播放接力推送
- **弹幕系统**：红果弹幕拉取与表情转换

### 原生桥接 (`native/bridge/`)

极简 Go 文件，仅有两个导出 C 函数：
- `DuanjuRequest(input *C.char) *C.char` — 入口
- `DuanjuFree(value *C.char)` — 释放

Flutter 端通过 `DynamicLibrary.open()` 加载编译产物：
- Android：`libduanju_core.so`
- Windows：`duanju_core.dll`
- iOS：`DynamicLibrary.process()`

## 6. 命令路由协议

Flutter ↔ Go 通过 JSON 文本协议通信。请求体结构：

```json
{
  "command": "catalog|detail|resolve|search|downloads|...",
  "source": "hongguo|yaguo|maoguo|...",
  "drama": { ... },
  "page": 1,
  "query": "...",
  "quality": 0,
  "settings": { ... }
}
```

响应体：
```json
{
  "ok": true,
  "items": [ ... ],
  "hasMore": true,
  "error": ""
}
```

## 7. 多平台支持矩阵

| 平台 | 优先级 | 状态 | 备注 |
| --- | --- | --- | --- |
| Android 手机 | P0 | 主要目标 | 前台服务下载、画中画 |
| Windows | P0 | 主要目标 | AI 画质增强、窗口管理 |
| Android TV | P1 | 适配中 | 遥控器焦点导航、横屏布局 |
| iOS | P2 | 暂缓 | 原生媒体库、后台任务限制 |
