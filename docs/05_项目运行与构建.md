## 2. Go 原生核心构建

### 2.1 Android（生成 libduanju_core.so）

```bash
cd native
export ANDROID_NDK_HOME=/path/to/ndk
export GOOS=android GOARCH=arm64 CGO_ENABLED=1 CC=$ANDROID_NDK_HOME/toolchains/llvm/prebuilt/linux-x86_64/bin/aarch64-linux-android21-clang

# 编译 .so
go build -buildmode=c-shared -o ../android/app/src/main/jniLibs/arm64-v8a/libduanju_core.so bridge/main.go
```

其他 ABI（armeabi-v7a, x86, x86_64）类似，替换 `GOARCH` 和 `CC`。

### 2.2 Windows（生成 duanju_core.dll）

```bash
cd native
GOOS=windows GOARCH=amd64 CGO_ENABLED=1 CC=x86_64-w64-mingw32-gcc \
    go build -buildmode=c-shared -o duanju_core.dll bridge/main.go
```

### 2.3 iOS（生成 framework）

```bash
cd native
# 需在 macOS + Xcode 环境
# 两种架构：arm64 (device) + amd64 (simulator)
GOOS=ios GOARCH=arm64 CGO_ENABLED=1 go build -buildmode=c-shared -o core-arm64.dylib bridge/main.go
# 然后 lipo 合并 → DuanjuCore.framework
```

iOS 端已提供 `DuanjuCore.podspec` 和 `DuanjuCoreAnchor`。

## 3. Flutter 构建

### 3.1 构建脚本

项目使用统一构建脚本 `scripts/app_build.py`：

```bash
# 红果鉴（默认，仅红果站源）
python3 scripts/app_build.py

# 真果鉴（全站源）
python3 scripts/app_build.py --all-sources

# 平台指定
python3 scripts/app_build.py --platform android      # APK
python3 scripts/app_build.py --platform windows      # EXE/MSIX
python3 scripts/app_build.py --platform ios          # IPA
python3 scripts/app_build.py --platform all           # 全部

# 打包发布
python3 scripts/package_release.py --all-sources
```

### 3.2 手动 Flutter 命令

```bash
# Debug 模式（红果鉴）
flutter run -t lib/main.dart

# Release APK
flutter build apk --release

# Release Windows
flutter build windows --release

# Debug APK（全站源，需先运行 app_build.py 生成变体文件）
flutter run --dart-define=ALL_SOURCES=true
```

> `app_build.py` 的作用是：根据 `--all-sources` 参数生成/替换 `lib/app_build.dart`（定义 `allSourcesEnabled` 常量和 appName），然后执行 Flutter build。

### 3.3 构建变体

```dart
// lib/app_build.dart（由 app_build.py 生成）
const bool allSourcesEnabled = true;  // 红果鉴 = false, 真果鉴 = true
const String appName = '真果鉴';
```

这个常量控制：
- `SourceSite.values` 包含全部站源 还是 仅 hongguo
- 首页是否显示所有站源入口
- Go 核心是否初始化非红果 Provider

## 5. 运行时行为

### 5.1 Android

- 首次启动：申请存储权限（下载目录）
- 下载：前台服务 + 通知栏进度
- PiP（画中画）：API 26+ 支持，手动触发
- 包体积：含 Go .so + media_kit + ffmpeg

### 5.2 Windows

- 窗口：默认尺寸 1080×1920，可拖动调整
- 画质增强：唯一支持平台（Anime4K + FSRCNNX shader）
- 全局快捷键：空格/方向键/M/F/Esc
- 下载：保持应用运行

### 5.3 iOS（暂缓）

- 下载：前台下载，后台暂停
- 媒体库：原生 Assets 框架集成（待实现）
- 后台任务：原生 BackgroundTasks（待实现）

## 6. 调试方法

### 6.1 Flutter 侧

```bash
# 普通调试
flutter run -d chrome    # Web 预览（无 Go 原生核心，fallback 到 mock）
flutter run -d windows   # Windows 桌面（含 Go .dll）
flutter run -d android   # Android 设备（含 Go .so）

# 附加调试器

```

> **重要**：Web 端（`flutter run -d chrome`）没有 Go 原生核心，FFI 调用会失败并返回 AppRepository 默认空实现。仅适合 UI 调试。

### 6.2 Go 侧

```bash
cd native/core

# 运行单元测试
go test ./... -v

# 单个文件测试
go test -run TestCatalog -v

# 覆盖率
go test ./... -coverprofile=coverage.out
go tool cover -html=coverage.out

go test -bench=BenchmarkCatalog -benchmem
```

```go
// diagnostics.go 提供的诊断日志

## 7. 目录约定

### 7.1 数据目录（设备端）

| 平台 | 路径 |
| --- | --- |
| Android | `/data/data/com.duanju.app/files/` 或用户选择的 SD 卡路径 |
| Windows | `%APPDATA%\duanju_app\` + 用户选择的下载目录 |
| iOS | `Documents/duanju_app/` |

目录结构：
```
[app_data]/
├─ downloads/           # 下载的原始视频文件
├─ catalog/             # 目录缓存 SQLite
├─ covers/              # 封面图片缓存
├─ preferences/         # SharedPreferences XML 文件
├─ sessions/            # 播放会话临时文件
└─ merge/               # 合并导出产物
```

### 7.2 源码目录

```
/workspace/
├─ lib/                 # Flutter UI 层
├─ native/
│   ├─ bridge/          # FFI 桥接 main.go
│   └─ core/            # Go 原生核心（101 文件）
├─ scripts/             # Python/PowerShell 构建脚本
├─ android/             # Android 平台工程
├─ ios/                 # iOS 平台工程
├─ windows/             # Windows 平台工程
├─ packages/            # 自定义 Flutter 插件

## 8. 版本发布流程

按 `AGENTS.md` 约定：

```bash
# 1. 修改 pubspec.yaml 版本号
# version: 0.2.55+61  →  version: 0.2.56+62

# 2. 执行收尾同步（会构建纯源码镜像 + 生成 zip）
python3 scripts/finish_task.py --message "本次实际完成的变更"

# 3. 验证同步一致
python3 scripts/sync_source.py --check
```

`finish_task.py` 行为：
- 同步干净源码到同级 `../guoapp`（排除 SDK、依赖目录、缓存、签名）
- 生成 `真果·鉴-YYYYMMDDHHMM.zip` 纯源码压缩包
- 同一分钟重复执行追加序号

## 9. 常见开发任务速查

| 任务 | 操作 |
| --- | --- |
| 新增短剧站源 | 在 `provider_duanju_dispatch.go` 添加 case + 新建 `provider_duanju_xxx.go` |
| 新增传统站源 | 新建 `provider_xxx.go` + 在 `Downloader` 添加字段 + `app_requests.go` 添加入口 |
| 新增分类接口 | 实现 `fetchXxxCategories()` + 在 `provider_duanju_dispatch.go` / `app_categories.go` 添加 |
| 调整并发/限流 | 修改 `defaultConfig()` → `Config.PageSize`, `Config.Retries` 或 `config_defaults.go` |
| 修改错误处理 | 各 `fetch*` / `resolve*` 方法返回 error，上层由 `app_requests.go` 统一包装 |
| 新增缓存策略 | `app_catalog_cache.go` / `app_covers.go` 分别管理目录和封面 |
| Flutter 调 Go 新接口 | `nativeInput` 增加字段 → `app_requests.go` 处理新 command → `NativeRepository` 加 Future 方法 |
